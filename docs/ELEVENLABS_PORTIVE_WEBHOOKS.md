# Portive sales webhooks: rollout and operations

This document covers only the two Portive **sales** Avas. It does not alter the
med-spa demo receptionist, Telnyx routing, calendar tools, or existing live CRM
tools. Apply in this order: database migration, application deploy, webhook UI,
then controlled calls. Do not enable a workspace-wide webhook until the agent
allowlist is set in Vercel.

## Secrets and deployment

In Vercel project **11labs-tools** → Settings → Environment Variables, add these
to Production (and Preview if you use it):

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
PORTIVE_TOOL_API_KEY                         # existing; do not rotate casually
PUBLIC_BASE_URL=https://11labs-tools.vercel.app
PORTIVE_WEBHOOK_ENABLED=true
PORTIVE_INITIATION_SECRET                    # new, distinct random value
ELEVENLABS_POSTCALL_WEBHOOK_SECRET           # generated by ElevenLabs UI
ELEVENLABS_API_KEY                           # server-only SDK client key
PORTIVE_INBOUND_AGENT_ID=agent_...
PORTIVE_OUTBOUND_AGENT_ID=agent_...
PORTIVE_SALES_NUMBER=+13103318914
```

Generate the initiation value locally, not in an agent prompt:

```bash
python3 -c 'import secrets; print(secrets.token_urlsafe(40))'
```

Keep `index.py` unchanged. Deploy the normal production branch, then check
`https://11labs-tools.vercel.app/health`. A request without the initiation key
must return 401; an unsigned post-call request must return 401. That is expected.

## ElevenLabs settings

UI labels change occasionally; look for the equivalent settings below.

1. Open **Ava | Portive Inbound Agent** → Security/Personalization → *Fetch
   initiation client data from a webhook*. Enable it for this inbound sales agent
   only. URL: `https://11labs-tools.vercel.app/webhooks/elevenlabs/initiation`.
   Add custom secret header `X-Portive-Initiation-Key` with the exact value of
   `PORTIVE_INITIATION_SECRET`.
2. Keep First Message exactly `Hello.`. Do not configure this webhook to override
   first message, prompt, voice, model, or any `system__` variable. Add dynamic
   placeholders only if used in the prompt: `business_name`, `owner_name`, `city`,
   `timezone`, `lead_id`, `prospect_phone_number`, `previous_context`, and optional
   `caller_match_status`/`prior_call_outcome`. Agent preview does not exercise an
   inbound initiation hook; use a consented SIP test call.
3. In **ElevenAgents → Settings** (or Developers → Webhooks), create a post-call
   webhook URL `https://11labs-tools.vercel.app/webhooks/elevenlabs/post-call`.
   Copy its generated HMAC secret into `ELEVENLABS_POSTCALL_WEBHOOK_SECRET` and
   redeploy. Enable `post_call_transcription` and `call_initiation_failure` and
   retries. Disable **Send audio data** / `post_call_audio`.
4. If post-call configuration is workspace-wide, that is acceptable only with both
   sales IDs in the Vercel allowlist above; the service acknowledges demo-agent
   deliveries without CRM mutation. Confirm it does not modify the demo agent.
5. Do not change the existing assignment of `+13103318914`, Telnyx SIP trunk, or
   outbound route here. Manually verify inbound Telnyx reaches the inbound Ava.

### Unknown inbound DNC webhook tool

Add this only to **Ava | Portive Inbound Agent**:

| Setting | Exact value |
|---|---|
| Name | `add_to_dnc_inbound_unknown` |
| URL | `https://11labs-tools.vercel.app/tools/add-to-dnc-inbound-unknown` |
| Method | `POST` |
| Header | `X-Portive-Tool-Key: {{secret PORTIVE_TOOL_API_KEY}}` |
| `conversation_id` | Required, Dynamic variable `{{system__conversation_id}}` |
| `reason` | Optional fixed `requested_no_contact` |

Never add caller phone as an LLM parameter. The server obtains it only from the
authenticated initiation audit for that conversation. If it returns
`manual_review_required`, the agent must not claim the caller was suppressed.
Known callers continue to use the existing `add_to_dnc` tool with actual
`lead_id`, `prospect_phone_number` (not inbound `system__called_number`), and
`system__conversation_id`. For unknown/ambiguous callers, prohibit the existing
known-lead email/callback/DNC tools.

## Verification SQL

```sql
select conversation_id,event_type,direction,lead_id,remote_phone_e164,call_outcome,
       failure_reason,sip_status_code,event_timestamp,received_at
from public.portive_call_events order by received_at desc limit 20;

select * from public.portive_call_events
where lead_id = 'CONTROLLED_TEST_LEAD_ID' or remote_phone_e164 = '+15125550123'
order by received_at desc;

select conversation_id,failure_reason,sip_status_code,sip_error_reason,remote_phone_e164,received_at
from public.portive_call_events where event_type='call_initiation_failure'
order by received_at desc limit 20;

select remote_phone_e164,count(*) from public.portive_call_events
where match_status in ('unknown','ambiguous') group by 1 order by count(*) desc;

select phone_e164,lead_id,conversation_id,reason,created_at from public.portive_dnc order by created_at desc;

select conversation_id,event_type,count(*) from public.portive_call_events
group by 1,2 having count(*) > 1; -- must be empty

select date_trunc('hour', received_at) hour,count(*) events,
       count(*) filter (where event_type='call_initiation_failure') failures
from public.portive_call_events where received_at > now()-interval '24 hours'
group by 1 order by 1 desc;
```

## Controlled rollout and rollback

Use one known test clinic number and one number you own. Exercise one harmless
callback conversation, one confirmed callback tool action, an explicit unknown
opt-out, known-lead DNC, and a controlled outbound sales test—never a real spa.
Verify Vercel statuses plus the SQL above. Continue screening every batch with
`python scripts/screen_batch_csv.py prospects.csv safe_batch.csv`; webhooks do
not implement a scheduler or prove dialing consent.

To roll back safely, disable initiation/post-call webhooks in ElevenLabs (or set
`PORTIVE_WEBHOOK_ENABLED=false` and redeploy). Leave old routes and event tables
in place; do not drop history. Restore the prior app release only after disabling
the external delivery configuration, otherwise retries will fail.
